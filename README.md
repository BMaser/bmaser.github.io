# bmaser.github.io

Static site for Bob Maser. Plain HTML/CSS, no build step. Edit the files and push to `main`; GitHub Pages serves the branch root.

- `index.html` - home page (video hero, About, Experience, Research, Skills, Publications, Education, Certifications, Contact)
- `research/` - one page per research area
- `courses.html` - teaching
- `assets/` - CSS, images
- `video/out/` - hero video files (rendered with the MathFlow tool kept in the Resume project)
